# Tools Overview

The Top Menu's Tools menu is where optional, pluggable tools live. Each entry shows a status dot (active/inactive); click a tool's name to activate or deactivate it. Which tools appear, and whether they are enabled by default, is controlled by your administrator (see [Admin - Plugins](admin_plugins.md)).

## Overlay tools

These add information on top of the normal timeline board and can be combined with each other:

- [Dependencies](plugin_dependencies.md) — draws dependency arrows between cards (toggled from the Top Menu's Scope menu, not the Tools menu).
- [Tool - Plan Events](plugin_events.md) — your own custom milestone markers, stored per scenario.
- [Tool - Plan Markers](plugin_markers.md) — Azure DevOps Delivery Plan milestones.
- [Tool - Annotations](plugin_annotations.md) — freehand notes, shapes and lines on the board.
- [Tool - Link Editor](plugin_link_editor.md) — create dependency links by clicking cards.
- [Tool - Plan Health](plugin_plan_health.md) — flags scheduling issues for review.
- [Tool - History & Revisions](plugin_history.md) — shows how dates changed over time.

## Full-screen views

These replace the timeline board with an alternative view of the same data:

- [Tool - Portfolio Board](plugin_portfolio.md) — Kanban board with teams as rows and states as columns.
- [Tool - XY Board](plugin_xyboard.md) — a 2D matrix of any two fields.
- [Tool - Graph Viewer](plugin_graph_viewer.md) — full-screen capacity allocation graph.
- [Tool - Cost Estimates & Teams](plugin_cost.md) — cost and hours reporting.

## Export

- [Tool - Export Timeline](plugin_export.md) — produce SVG/PNG or clipboard images of the current board.
